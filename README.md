# Verdant Micro & Sprout Co. (Global Edition)

Artisanal, luxury e-commerce web application for living microgreens, sulforaphane broccoli sprouts, and custom harvest boxes.

## Features
- **Interactive Growth Stage Visualizer**: Compares sprouts and microgreens through harvest cycles.
- **Nutrient Matchmaker Quiz**: Identifies ideal varieties for cellular detoxification, gut health, and athletic recovery.
- **Custom Harvest Box Builder**: Real-time tray capacity calculation and subscription savings.
- **Cart & Cold-Chain Logistics**: Slide-over drawer with coupon codes and live checkout simulator.

## Getting Started
1. Run `npm install`
2. Run `npm start`
3. Open `http://localhost:3000` in your browser.
